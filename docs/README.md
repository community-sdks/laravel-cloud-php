SDK is developed from official Laravel Cloud endpoint documentation and
OpenAPI definitions, one endpoint at a time.

## Endpoint status

The HTTP foundation and service accessors are available. No endpoint method is
listed as supported until its official contract has been supplied, implemented,
and tested. This keeps these docs aligned with the public PHP API.

Every implemented endpoint will be documented on its service page with its PHP
method, HTTP route, request type, response type, exceptions, and an example.
